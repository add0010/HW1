# 退出登录功能测试指南

## 已实现的改进

### 1. 界面改进
- ✅ 将"断开连接"按钮改为**"退出登录"**
- ✅ 按钮文字更符合用户习惯

### 2. 退出登录流程
```
用户点击"退出登录" 
  ↓
显示确认对话框 (显示当前用户和服务器信息)
  ↓
用户确认后向服务器发送退出请求
  ↓
关闭TLS连接
  ↓
清理本地会话状态:
  - 清空密码输入框
  - 清空文件列表
  - 清空用户名
  ↓
显示成功提示
```

### 3. 会话状态清理
退出登录时会自动清理:
- ✅ **密码输入框** - 防止密码泄露
- ✅ **远程文件列表** - 清空显示
- ✅ **用户名状态** - 重置为未登录
- ✅ **网络连接** - 优雅关闭TLS会话

### 4. 用户体验优化
- ✅ **确认对话框** - 显示当前登录信息,避免误操作
- ✅ **成功提示** - 退出后显示友好提示
- ✅ **状态栏更新** - 清晰显示"已退出登录"
- ✅ **按钮状态管理** - 自动启用/禁用相关按钮

### 5. 关闭窗口改进
- ✅ **登录状态检测** - 关闭窗口时检查是否已登录
- ✅ **二次确认** - 登录状态下关闭窗口需确认
- ✅ **优雅退出** - 自动向服务器发送退出请求

### 4. 关闭窗口改进
```python
def _on_close(self) -> None:
    # 检查是否登录
    if self.sock is not None:
        if not messagebox.askyesno(
            "确认退出",
            f"您当前已登录为 {self.username}。\n关闭窗口将断开连接。\n\n确定要退出吗？",
            parent=self
        ):
            return
    # 优雅退出
    try:
        send_json(self.sock, {"op": "quit"})
    except Exception:
        pass
```
