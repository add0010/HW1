## 🔐 证书文件说明

生成的证书位于 `certs/mtls/`:

| 文件 | 说明 | 用途 |
|------|------|------|
| `ca-cert.pem` | CA根证书 | 服务器和客户端都需要信任 |
| `ca-key.pem` | CA私钥 | 签发证书用 (生产环境需保密) |
| `server-cert.pem` | 服务器证书 | 服务器身份认证 |
| `server-key.pem` | 服务器私钥 | 🔒 私密 |
| `client-cert.pem` | 客户端证书 | 客户端身份认证 |
| `client-key.pem` | 客户端私钥 | 🔒 私密 |

**⚠️ 安全提醒:**
- 所有 `*-key.pem` 文件是私钥,不要分享或提交到Git
- 这些证书仅用于开发测试,不适合生产环境

## ❓ 故障排除

### 问题1: "找不到 OpenSSL"

**解决方案:**
1. 安装 **Git for Windows** (推荐,包含OpenSSL)
   - 下载: https://git-scm.com/download/win
   
2. 或单独安装 OpenSSL
   - 下载: https://slproweb.com/products/Win32OpenSSL.html
   - 选择 "Win64 OpenSSL v3.x.x" 完整版

### 问题2: "无法加载证书"

检查证书是否存在:
```bash
dir certs\mtls\*.pem
```

如果缺失,重新生成:
```bash
cd scripts
.\generate_certs_auto.ps1
```

### 问题3: PowerShell脚本执行被阻止

临时允许:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

或右键脚本 → 属性 → 解除锁定

### 问题4: "Module not found: cryptography"

安装依赖:
```bash
pip install cryptography PyQt5
```

### 问题5: 服务器启动失败 "Address already in use"

端口被占用,修改 `server.py` 中的端口:
```python
PORT = 8444  # 改为其他端口
```
