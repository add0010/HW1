退出登录功能 - 实现说明
================================================================

🎯 实现目标
-----------
为GUI客户端添加完整的"退出登录"功能,替代原来简单的"断开连接"

✨ 主要改进
-----------
1. 按钮重命名
   旧: "断开连接"  →  新: "退出登录"
   
2. 添加确认对话框
   旧: 直接断开  →  新: 显示当前用户信息,确认后退出
   
3. 完整的状态清理
   - 清空密码输入框 (防止密码泄露)
   - 清空文件列表
   - 重置用户名状态
   - 关闭TLS连接
   
4. 用户反馈优化
   - 退出成功提示框
   - 状态栏显示"已退出登录"
   
5. 关闭窗口改进
   - 检测登录状态
   - 登录时关闭窗口需二次确认
   - 自动向服务器发送退出通知

📋 使用方法
-----------
1. 登录成功后,点击左侧的"退出登录"按钮
2. 确认对话框会显示:
   ┌─────────────────────────────────┐
   │ 确定要退出登录吗？              │
   │                                 │
   │ 当前用户: alice                 │
   │ 服务器: 127.0.0.1:9443          │
   │                                 │
   │    [ 是(Y) ]    [ 否(N) ]      │
   └─────────────────────────────────┘

3. 点击"是"后会自动:
   - 向服务器发送退出请求
   - 关闭TLS连接
   - 清空密码框
   - 清空文件列表
   - 显示退出成功提示

4. 退出后可以:
   - 重新输入用户名密码登录
   - 切换到其他账户
   - 安全地关闭程序

🔐 安全性提升
-------------
✅ 密码保护
   - 退出登录时自动清空密码输入框
   - 防止他人看到保存的密码

✅ 会话隔离
   - 退出时清空所有用户数据
   - 防止账户间数据混淆

✅ 优雅退出
   - 通知服务器正常退出
   - 服务器可记录完整的会话日志

✅ 防误操作
   - 二次确认机制
   - 清晰的状态提示

🎨 UI状态变化
--------------
登录前:
  [连接并登录] ✓ 可用
  [退出登录]   ✗ 禁用
  
登录后:
  [连接并登录] ✗ 禁用
  [退出登录]   ✓ 可用
  
退出后:
  [连接并登录] ✓ 可用
  [退出登录]   ✗ 禁用
