场景1: 临时离开 💼
─────────────────
需求: 用户需要临时离开电脑,但不想关闭程序

操作步骤:
1. 点击 [退出登录]
2. 确认退出
3. ✅ 密码已清空 → 他人无法看到密码
4. ✅ 文件列表已清空 → 保护隐私
5. 离开电脑,安心! 😊

回来后:
1. 重新输入密码登录
2. 继续使用


场景2: 切换账户 🔄
─────────────────
需求: 想切换到另一个账户查看文件

操作步骤:
1. 点击 [退出登录]
2. 确认退出
3. 输入新的用户名: bob
4. 输入新的密码: bob456
5. 点击 [连接并登录]
6. ✅ 成功登录 bob 账户
7. ✅ 看到 bob 的文件列表


场景3: 误操作保护 ⚠️
────────────────────
场景: 不小心点到了退出按钮

旧版本体验:
❌ 直接退出,无法撤销
❌ 需要重新登录

新版本体验:
✅ 弹出确认框
✅ 点击 [否] 取消操作
✅ 保持登录状态
✅ 继续工作!


场景4: 安全关闭程序 🔐
──────────────────────
需求: 完成工作,关闭程序

操作步骤:
1. 点击窗口 [×]
2. ✅ 系统检测到还在登录
3. ✅ 弹出确认: "您当前已登录为 alice..."
4. 点击 [是] 确认
5. ✅ 自动向服务器发送退出通知
6. ✅ 优雅关闭连接
7. 窗口关闭
