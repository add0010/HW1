┌────────────────────────────────────────────────────────────────┐
│ 🎯 功能概述                                                    │
└────────────────────────────────────────────────────────────────┘
为GUI客户端添加完整的"退出登录"功能，包括确认对话框、
状态清理和安全保护。

┌────────────────────────────────────────────────────────────────┐
│ ⚡ 快速使用                                                    │
└────────────────────────────────────────────────────────────────┘
1. 登录后点击 [退出登录] 按钮
2. 确认对话框中点击 [是]
3. ✓ 自动清空密码和文件列表
4. ✓ 显示退出成功提示

┌────────────────────────────────────────────────────────────────┐
│ ✨ 5个核心改进                                                 │
└────────────────────────────────────────────────────────────────┘
1. 按钮文字: "断开连接" → "退出登录"
2. 确认对话框: 显示用户和服务器信息
3. 密码清理: 退出时自动清空密码框
4. 成功提示: 操作完成显示友好提示
5. 窗口检测: 关闭时检查登录状态

┌────────────────────────────────────────────────────────────────┐
│ 🔒 安全提升                                                    │
└────────────────────────────────────────────────────────────────┘
✓ 自动清空密码输入框 → 防止密码泄露
✓ 清空文件列表显示 → 保护隐私
✓ 清理用户名状态 → 防止会话混淆
✓ 优雅断开连接 → 完整日志记录

┌────────────────────────────────────────────────────────────────┐
│ 📋 退出登录流程                                                │
└────────────────────────────────────────────────────────────────┘
点击 [退出登录]
    ↓
显示确认对话框 (用户: alice, 服务器: 127.0.0.1:9443)
    ↓
用户确认 [是]
    ↓
向服务器发送 {"op": "quit"}
    ↓
关闭TLS连接
    ↓
清理本地状态 (密码、文件、用户名)
    ↓
显示"退出成功"
    ↓
完成 ✓

┌────────────────────────────────────────────────────────────────┐
│ 🎨 界面变化                                                    │
└────────────────────────────────────────────────────────────────┘
登录前:
  [连接并登录] ✓ 可用    [退出登录] ✗ 禁用

登录后:
  [连接并登录] ✗ 禁用    [退出登录] ✓ 可用

退出后:
  [连接并登录] ✓ 可用    [退出登录] ✗ 禁用
  密码框: 已清空 ✓       文件列表: 已清空 ✓

┌────────────────────────────────────────────────────────────────┐
│ 🧪 测试场景                                                    │
└────────────────────────────────────────────────────────────────┘
场景1: 正常退出
  登录 → 退出登录 → 确认 → ✓ 状态已清理

  alice登录 → 退出 → bob登录 → ✓ 数据隔离

场景4: 关闭窗口
  登录 → 点击[X] → 确认 → ✓ 优雅退出

┌────────────────────────────────────────────────────────────────┐
│ 💡 使用技巧                                                    │
└────────────────────────────────────────────────────────────────┘
• 临时离开: 退出登录保护密码和文件
• 切换账户: 退出后重新登录其他账户
• 误操作: 确认对话框可以取消
• 关闭程序: 自动检测登录状态提醒

┌────────────────────────────────────────────────────────────────┐
│ ⚠️ 注意事项                                                    │
└────────────────────────────────────────────────────────────────┘
• 退出登录会清空密码框，需要重新输入
• 退出后文件列表会清空，需要重新刷新
• 正在传输文件时无法退出，需等待完成
• 关闭窗口会自动执行退出登录流程
