# 更新日志 - 退出登录功能

## v2.0 - 2026-11-10

### 🎉 新增功能

#### 1. 完整的退出登录功能
- **按钮重命名**: "断开连接" → "退出登录" (更符合用户习惯)
- **退出确认对话框**: 显示当前登录用户和服务器信息,防止误操作
- **退出成功提示**: 操作完成后显示友好的成功提示
- **完整状态清理**: 自动清空密码框、文件列表和用户状态

#### 2. 关闭窗口改进
- **登录状态检测**: 关闭窗口时检测是否处于登录状态
- **二次确认机制**: 登录状态下关闭窗口需要用户确认
- **优雅退出**: 自动向服务器发送退出通知

### 🔒 安全性提升

- ✅ **密码保护**: 退出登录时自动清空密码输入框
- ✅ **会话隔离**: 清空所有用户相关数据,防止账户混淆
- ✅ **优雅断开**: 通知服务器正常退出,完整记录会话日志

### 🎨 用户体验优化

- ✅ **清晰的按钮文字**: "退出登录"更易理解
- ✅ **防误操作**: 多层确认机制
- ✅ **即时反馈**: 操作状态实时显示
- ✅ **状态提示**: 详细的状态栏信息
