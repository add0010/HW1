## 📋 附录：核心实现要点速查

### 应用层协议设计

**帧格式：**
```
[4字节长度前缀][JSON控制头][可选二进制载荷]
```

**关键方法：**
- `send_json()` / `recv_json()` - 发送接收控制帧
- `send_stream()` / `recv_stream()` - 流式传输文件，实时计算 SHA-256
- `recv_exact()` - 精确读取指定字节数，支持超时和进度回调

### 认证机制

**客户端：**
```python
# 双向 TLS 握手
context = ssl.create_default_context(cafile=ca_cert)
context.load_cert_chain(certfile=client_cert, keyfile=client_key)
secured = context.wrap_socket(raw, server_hostname=host)

# 账号密码认证（在 TLS 通道内）
send_json(secured, {"op": "auth", "username": username, "password": password})
```

**服务端：**
```python
# PBKDF2 密码验证
salt = base64.b64decode(user["salt"])
expected = base64.b64decode(user["hash"])
actual = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, 310_000)
if not hmac.compare_digest(expected, actual):
    raise AuthenticationError()
```

### 并发与隔离

**服务端线程模型：**
```python
class ThreadedTCPServer(socketserver.ThreadingMixIn, socketserver.TCPServer):
    allow_reuse_address = True
    daemon_threads = True
```

**用户目录隔离：**
```python
user_dir = storage_path / username
file_path = user_dir / filename
# 拒绝路径分隔符和危险字符
if not NAME_RE.fullmatch(filename):
    raise ValueError("invalid filename")
```

### 文件传输完整性

**上传流程：**
1. 客户端计算本地文件 SHA-256
2. 发送 `{"op": "upload", "name": "...", "size": ..., "sha256": "..."}`
3. 服务器检查配额和文件名
4. 客户端分块传输（1 MiB/块）
5. 服务器计算接收文件 SHA-256
6. 校验通过后原子替换：`os.replace(temporary, target)`

**下载流程：**
1. 客户端发送 `{"op": "download", "name": "..."}`
2. 服务器返回文件大小和 SHA-256
3. 服务器分块传输文件内容
4. 客户端逐块更新哈希，最终对比
5. 校验通过后原子替换本地文件

### 安全边界控制

```python
# 并发限制
MAX_CONNECTIONS = 64

# 资源限制
MAX_FILE_SIZE = 512 * 1024 * 1024  # 512 MiB
MAX_USER_STORAGE = 2 * 1024 * 1024 * 1024  # 2 GiB

# 认证限速
AUTH_FAILURES_PER_IP = 5  # 每IP每分钟最多5次失败

# 协议限制
MAX_HEADER_SIZE = 64 * 1024  # 控制头最大64 KiB
SOCKET_TIMEOUT = 90  # 空闲超时90秒
```
