# 使用与录屏指南

本指南用于在 Windows 本机运行安全文件传输项目，并按实验要求录制“编译、部署、测试”的完整过程。录制前准备一个不含个人隐私的测试文件，建议 1–5 MiB。

## 一、首次准备

打开 PowerShell，进入项目目录：

```powershell
Set-Location D:\workspace\projects\python\hw\hw4\1B_secure_file_transfer
```

确认 Python 与 Tkinter 可用：

```powershell
py --version
py -c "import tkinter; print('Tkinter', tkinter.TkVersion)"
```

Windows 上使用 PowerShell 7 生成一组仅供课程演示的证书（首次运行一次即可）：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\generate_demo_cert.ps1
```

生成结果位于 `certs\mtls`。服务端使用 `server-cert.pem` 和 `server-key.pem`；双方信任 `ca-cert.pem`；图形客户端使用 `client-cert.pem` 和 `client-key.pem`。证书脚本若提示文件已存在，请不要反复生成；演示证书目录已准备好时可直接继续。

创建两个尚未存在的测试用户：

```powershell
py server.py add-user student_a
py server.py add-user student_b
```

每个密码至少 12 个字符，输入时终端不显示字符。若用户名已存在，选择其他用户名即可。服务端启动时会读取 `users.json`，因此应在启动服务端之前创建两个账号。

可选：录屏时展示 Python 文件编译成功：

```powershell
py -m compileall -q server.py client.py client_gui.py protocol.py
```

## 二、启动服务端与客户端

在 PowerShell 窗口 A 启动服务端：

```powershell
Set-Location D:\workspace\projects\python\hw\hw4\1B_secure_file_transfer
py server.py serve --host 0.0.0.0 --port 9443
```

服务端启动后保持该窗口打开。另开 PowerShell 窗口 B，启动客户端：

```powershell
Set-Location D:\workspace\projects\python\hw\hw4\1B_secure_file_transfer
py client_gui.py
```

界面默认服务器地址和端口为 `127.0.0.1`、`9443`。先填入 `student_a` 和创建时设置的密码，再点“连接并登录”。证书路径默认在 `certs\mtls`；如果目录移动过，请用“浏览”按钮重新选择 CA 证书、客户端证书和客户端私钥。

## 三、界面操作

1. 为展示认证失败处理，可先用错误密码尝试登录一次；界面应显示通用认证失败。之后输入正确密码重新登录。
2. 点击“选择文件上传”，在弹出的系统窗口中选择本地测试文件。
3. 等待进度结束，确认文件出现在右侧远端列表，状态栏显示 SHA-256 校验通过。
4. 点击“测试长连接”，确认提示连接仍正常；再刷新列表。登录后多个操作共用同一条 TLS/TCP 连接。
5. 选中刚上传的文件，点击“下载所选”，选择另一个本地目录保存。
6. 在 PowerShell 比较原文件和下载文件的摘要：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "C:\路径\原始测试文件.bin"
Get-FileHash -Algorithm SHA256 -LiteralPath "C:\路径\下载文件.bin"
```

两条命令的 `Hash` 值应相同。也可以双击远端文件开始下载。

## 四、并发与用户隔离演示

在窗口 C 再启动一个 `py client_gui.py`，使用 `student_b` 登录。两个界面保持连接时，在窗口 A 的 `student_a` 会话和窗口 C 的 `student_b` 会话分别上传不同文件。服务端日志应能看到两名用户的认证与操作；项目的存储目录为 `storage\student_a` 和 `storage\student_b`，两个账号只能看到各自目录中的文件。每个服务端最多同时处理 64 个连接。

服务端的多用户并发限制、认证限速、超时、文件大小限制和配额可以在 `server.py` 与报告中展示。录屏中无需发送攻击流量；SQL 注入通过“不使用 SQL 数据库”消除查询入口。

## 五、建议录屏顺序

可按 4–6 分钟录制，镜头中避免显示密码和私钥内容：

1. 展示项目文件，说明使用 Python 标准库和 Tkinter 图形界面。
2. 运行 `py -m compileall -q ...`，展示命令成功返回。
3. 展示演示 CA/服务端/客户端证书生成结果；不打开私钥文件。
4. 创建两个测试账号，并在终端中启动服务端。
5. 图形客户端用错误密码登录一次，再以正确密码成功登录。
6. 点击“选择文件上传”，选取本地文件，展示上传进度和远端列表。
7. 点击“测试长连接”，随后再次刷新或上传文件，说明会话仍保持。
8. 下载同一文件到另一目录，用 `Get-FileHash` 展示两份文件摘要一致。
9. 打开第二个客户端窗口，以另一个用户并发登录并上传文件；展示用户目录相互隔离。
10. 简要展示代码/报告中的 TLS 双向认证、长度前缀协议、SHA-256、并发上限、认证限速、文件大小/配额和不使用 SQL 的设计。最后在服务端窗口按 Ctrl+C 停止服务。

## 六、常见问题

- **找不到 Tkinter**：安装带 Tcl/Tk 的 Windows Python，然后再运行 `py client_gui.py`。
- **找不到 `pwsh`**：安装 PowerShell 7 后运行上面的证书脚本。Linux/macOS 用户可运行 `scripts/generate_demo_cert.sh`，该脚本需要 OpenSSL。
- **证书验证失败**：确认 GUI 的 CA、客户端证书和私钥来自同一 `certs\mtls` 目录；本机连接时服务器地址应为 `127.0.0.1` 或 `localhost`。
- **认证失败**：确认服务端 `users.json` 中存在该用户并输入创建时的密码。失败信息有意统一；服务端对同一 IP 的失败尝试会限速。
- **端口无法访问**：本机演示先使用 `127.0.0.1:9443`；跨电脑演示需配置防火墙、证书 SAN 和实际服务端地址。
- **证书文件已存在**：生成脚本不会覆盖已有私钥。确认要重建前，先备份或手动移走旧演示证书，再重新运行脚本。
